# learn-lesson：按规划生成当日图文课程

## 第零步：定位学习工作区

1. 找到规划文件：先看当前目录有没有 `plan.md` + `progress.json`，再看 `~/learn/<主题slug>/`。都没有 → **不要自己擅自规划**，提示用户先说"我想学 X"触发 learn-plan。
2. 确定要生成哪一天：用户指定了天数就用指定的；否则取 `progress.json` 里第一个 `status: "pending"` 的天。
3. 读三样东西：`plan.md` 中该天的条目（知识点、寓言适配、配图标注、过关标准）、`progress.json` 的 `weakPoints`（本课要主动绕开或加固它们）、以及该天先修知识点的课程文件（保证衔接）。

## 第一步：寓言导入（互动式，流程见 references/fable-examples.md）

按 plan.md 标注的寓言适配执行：

- **`fable`**：完整执行寓言四步。**在交互式会话中必须真的停下来等用户回答**，不要一口气把课讲完：
  1. 在对话中直接给出三段式故事（有冲突、有取舍，全程不出现概念名）；
  2. 问用户："你觉得这个故事在讲什么道理？"
  3. **等待用户回答**。对用户的回答给出反馈（对了确认，错了温和但明确地指出偏差）；
  4. 揭晓名字，逐要素回扣故事情节。
- **`variant`**：用标注的替代文体（侦探小说/未来备忘录/童话…）执行同样的四步。
- **`direct`**：跳过寓言，直接进入讲解 + 动手操作。

用户不在线或明确要求"一次出完整资料"时：把问题写进文档（"停下来想一想"节），揭晓部分放在文档末尾并加"先回答上面的问题再往下读"的提示，保证独自阅读的人也能自测。

## 第二步：写入 day-NN.md

文件结构见 `references/lesson-template.md`，必须包含：今日目标 → 寓言（含用户刚才的回答与反馈记录）→ 概念揭示与逐要素回扣 → 正式讲解（定义、边界情况、常见误区）→ 图解 → 主动回忆自测（5 题，答案在文末）→ 明日预告。

## 第三步：配图（按 plan.md 的配图标注）

对标注了图型的知识点：

1. **优先使用本机 archify skill**：按其流程写 `<slug>.<type>.json` → 渲染 → 校验，产出：
   - `diagrams/<slug>.<type>.html`（交互版，浏览器打开可切换主题、导出 PNG/SVG）
   - `diagrams/<slug>.<type>.svg`（静态版，内联进 Markdown：`![图解：<标题>](diagrams/<slug>.<type>.svg)`）
2. SVG 静态版的生成：优先用 dsh-learn-plugin 仓库的转换脚本
   `node scripts/html2svg.mjs <渲染出的html> <输出svg>`（从 archify HTML 提取主图并改写为
   `prefers-color-scheme` 双主题独立 SVG）。注意卡片（cards）是 HTML 元素、不在 SVG 里，
   所以 Markdown 的读图指引段落必须把卡片要点写全。脚本不可用时按 archify 的
   设计系统（CSS 变量、语义 class、双主题）手写独立 SVG。
3. 图的配色遵循 archify 的语义 class（`c-frontend`/`c-backend`/`c-database`…），不要内联随意颜色；图的标题和图例用中文。
4. **标注为 `none` 的知识点不要配图**，硬凑的图比没有图更碍事。
5. 生成后把图的路径追加到 `plan.md` 的"寓言与图索引"。

## 第四步：更新进度与收尾

1. 更新 `progress.json`：该天 `status` 置为 `"in-progress"`；课程生成完成即置 `"done"` 并记 `completedAt`（但若有薄弱点，把从用户寓言回答和自测中观察到的写进 `weakPoints` 与知识点 `mastery`）。
2. 更新 `plan.md` 的"寓言与图索引"（本课的寓言载体一句话 + 图路径）。
3. 收尾话术：告诉用户自测怎么用（先答再看文末答案，答完把不确定的题反馈给你来记录薄弱点），以及明天说"继续学习"即可。

## 质量底线

- **故事里出现概念名 = 重写**。这是本方法的第一铁律。
- 寓言控制在约 300 字内；短比长好。
- 讲解部分语言平实，每一个抽象说法都要能回溯到故事里的具体情节。
- 自测第 1-2 题考回忆、3-4 题考新情境应用、第 5 题考挑错或反向费曼
  （"把这个定义还原成一个不点名的三段式故事"或"这个故事漏掉了概念的哪个方面"）。
- 全文用中文（专有名词保留英文原文）。
